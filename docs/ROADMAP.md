# Roadmap

Version 1.0.0 delivers the documented first workflow. The following are planned, not shipped:

- Opt-in reading sessions to learn whether capture cost is justified.
- A user-reviewed Netscape-bookmark import with explicit capacity and duplicate handling.
- Keyboard reading actions and a measured VoiceOver pass.

Improvements should be justified by observed use or a reproducible bug. Avoid fake activity commits and unsupported adoption claims.
